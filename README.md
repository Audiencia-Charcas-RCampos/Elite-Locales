# Elite-Locales
Atlas histórico digital sobre las élites locales de Jujuy y su vínculo con los núcleos de poder de Charcas en el siglo XVII. Incluye un mapa interactivo con territorios, la Real Audiencia, la Gobernación del Tucumán, capitales, ciudades y minas, además de fichas históricas y un apartado sobre el rol de las mujeres.
